# Application mobile TicketSûr (Flutter, Android d'abord)

Initialisée en Phase 1 (`flutter create --org <identifiant> --platforms android`). L'identifiant d'application Android est définitif une fois publié sur Google Play : il doit être validé avant cette étape.

`assets/branding/` contient les actifs officiels : ne pas les redessiner ; seules les variantes techniques (icône adaptative, splash, monochrome) en seront dérivées.
